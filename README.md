# Australia's Threatened Species

An interactive data visualization project exploring Australia's threatened biodiversity through maps, charts, and taxonomic relationships.

## About the Project

This project visualizes threatened species data to explore their geographic distribution, conservation status, taxonomic classification, and changes over time. Interactive visualizations allow users to investigate biodiversity patterns and compare different species groups.

## Data Sources

- [Threatened Species State Lists — Data.gov.au](https://data.gov.au/data/dataset/threatened-species-state-lists)
- [Australian Threatened Species Index (TSX) 2024](https://tsx.org.au/tsx2024/)

## Visualizations Used

- Choropleth Map
- Proportional Symbol Map
- Dot Density Map
- Tornado Chart
- Radial Stacked Bar Chart
- Sankey Diagram
- Sunburst Diagram
- Stream Graph
- Connected Dot Plot
- Bump Chart

## Features

- Interactive maps and charts
- Geographic comparison of threatened species
- Taxonomic hierarchy exploration
- Filtering by taxonomic group
- Data-driven visual storytelling
